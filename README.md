# aitooldirectory
Directory of 900 AI Tools, with links, descriptions, titles and categories. Free to use and reuse. Pay it forward

## Uses
- **[LetsVibeAI](https://github.com/diamitani/letsvibe-academy)** — the dataset powers the [AI Tools Directory](https://letsvibeai.com/tools) (820+ deduped, cleaned tools). Regenerated via `scripts/import-ai-directory.py` in that repo.
